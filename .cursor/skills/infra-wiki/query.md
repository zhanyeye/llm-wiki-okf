# query

1. 读 [`wiki/index.md`](../../../wiki/index.md)。
2. 只知道现象（磁盘满、Helm 失败、找不到进程）→ 读 [`wiki/故障排查/index.md`](../../../wiki/故障排查/index.md)。
3. 已知系统名 → `wiki/系统与架构/`；找入口/负责人/日志路径 → `wiki/资源注册表/`。
4. 打开 **2–5** 篇正文作答，引用路径（如 `wiki/操作手册/disk-full.md`）。
5. 仍不够再搜索 frontmatter 的 `tags` / `domain` / `services` / `title`。

缺了的内网细节（集群名、VIP、凭证、未写步骤）直接说「wiki 里没有」，并建议按 [ingest.md](ingest.md) 补页。不要编。

若本次整理出新的排查树、对比表或决策摘要，问用户是否回写成新页（[author.md](author.md)）。

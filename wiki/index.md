# 基础设施知识库

人和 Agent 读同一套 Markdown。先读本页看分组，再打开对应目录（有 `index.md` 则先读它），最后打开相关正文。分组尚无概念页时可以没有 `index.md`；写入第一篇时由 Agent 创建。

## 分组

* [资源注册表](./资源注册表/) - 资源、入口、环境、负责人、依赖、告警。不存凭证
* [系统与架构](./系统与架构/) - 系统说明、拓扑、请求与数据链路
* [操作手册](./操作手册/) - 标准操作、配置说明与脚本用法
* [故障排查](./故障排查/) - 按症状排查（场景预案）；值班入口
* [架构决策记录](./架构决策记录/) - 选型、权衡、约束
* [常见问题](./常见问题/) - 短问答、工具速查、报错释义
* [案例与复盘](./案例与复盘/) - 故障、变更、演练复盘
* [新人上手](./新人上手/) - 接手清单、首周任务与学习路径
